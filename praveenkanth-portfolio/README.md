# Praveenkanth Portfolio

Modern, multi-page developer portfolio built with **Next.js 15 + TypeScript + Tailwind CSS v4**.

## Stack
- Next.js App Router · React 19 · TypeScript
- Tailwind CSS v4 (utilities only, no custom CSS)
- Lucide React icons
- localStorage theme persistence
- GitHub public API (with static fallback)

## Themes (exactly 5)
1. Midnight Indigo (default)
2. Glassmorphism
3. Claymorphism
4. Retrofuturism
5. Y2K

## Scripts
```bash
npm install
npm run dev     # localhost:3000
npm run build   # production build
npm start
